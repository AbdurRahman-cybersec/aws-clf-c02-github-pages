# Quiz 2.0

1. A change or failure in one component should not cascade to other components.
    Answer: Loose coupling

2. A gateway that enables Amazon EC2 instances in a public subnet to connect to the public internet.
    Answer: Internet Gateway

3. A gateway that enables EC2 instances in a private subnet to connect to the public internet.
    Answer: NAT Gateway

4. A security management tool used to configure AWS WAF rules across accounts.
    Answer: AWS Firewall Manager

5. Provides compliance-related documents such as Service Organization Control (SOC) reports.
    Answer: AWS Artifact

6. An IAM identity that uses access keys to manage cloud resources through the AWS CLI.
    Answer: IAM User

7. An IAM identity that grants temporary access to AWS resources.
    Answer: IAM Role

8. Manages common access permissions for a large number of IAM users.
    Answer: IAM Group

9. A resource-based policy used to grant permissions to an S3 bucket and its objects.
    Answer: Bucket Policy

10. Provides AWS credentials that grant application users access to other AWS services.
    Answer: Amazon Cognito Identity Pools

11. Discovers, classifies, and helps protect sensitive data such as PII or intellectual property.
    Answer: Amazon Macie

12. A threat-detection service that continuously monitors for malicious activity in an AWS account.
    Answer: Amazon GuardDuty

13. An authentication method that can prevent unauthorized deletion of protected Amazon S3 objects.
    Answer: Multi-Factor Authentication (MFA)

14. A virtual firewall that controls traffic at the EC2 instance level.
    Answer: Security Group

15. An automated security-assessment service that improves the security and compliance of applications.
    Answer: Amazon Inspector

16. Uses the AWS global network and anycast static IP addresses to improve application availability and performance.
    Answer: AWS Global Accelerator

17. A secure data-transport service used to move petabyte-scale data into and out of AWS.
    Answer: AWS Snowball

18. Continuously records account activity, including actions performed through the AWS Management Console and SDKs.
    Answer: AWS CloudTrail

19. A source-control service for hosting Git-based repositories.
    Answer: AWS CodeCommit

20. An EC2 option that supports existing server-bound software licenses.
    Answer: Dedicated Host

21. A highly available and scalable cloud DNS service.
    Answer: Amazon Route 53

22. Automatically adjusts the capacity of AWS resources based on demand.
    Answer: AWS Auto Scaling

23. Automatically transfers infrequently accessed S3 data to a more cost-effective storage class.
    Answer: S3 Lifecycle Policy

24. A designated technical point of contact who helps maintain an operationally healthy AWS environment.
    Answer: Technical Account Manager (TAM)

25. Inspects an AWS environment and recommends improvements based on AWS best practices.
    Answer: AWS Trusted Advisor

26. Lets you set coverage targets and receive alerts when utilization falls below them.
    Answer: AWS Budgets

27. A Reserved Instance type that allows changes to instance family, instance type, platform, scope, or tenancy.
    Answer: Convertible RI

28. Forecasts future AWS costs and usage based on past consumption.
    Answer: AWS Cost Explorer

29. Categorizes and tracks AWS costs at a detailed level.
    Answer: Cost allocation tags

30. The most cost-effective payment option in this set when purchasing a Reserved Instance for a one-year term.
    Answer: All Upfront

31. A managed service that simplifies deploying, operating, and scaling distributed in-memory caches.
    Answer: Amazon ElastiCache

32. A managed migration and replication service for moving database and analytics workloads to AWS with minimal downtime.
    Answer: AWS Database Migration Service (AWS DMS)

33. Provides a dedicated 1 Gbps or 10 Gbps fiber connection between an on-premises location and AWS without using the public internet path.
    Answer: AWS Direct Connect

34. A machine learning service that adds image and video analysis to applications.
    Answer: Amazon Rekognition

35. Helps analyze distributed application behavior through profiling, exception collection, and request tracing.
    Answer: AWS X-Ray

36. Data associated with an EC2 instance that applications can use to configure or manage the instance while it runs.
    Answer: Instance metadata

37. Accelerates delivery of dynamic and static web content such as images, JavaScript, CSS, and HTML.
    Answer: Amazon CloudFront

38. Defines and deploys AWS resources using infrastructure as code.
    Answer: AWS CloudFormation

39. Creates, manages, and controls cryptographic keys for AWS services and applications.
    Answer: AWS Key Management Service (AWS KMS)

40. A serverless, fully managed NoSQL key-value database for high-performance applications at any scale.
    Answer: Amazon DynamoDB

41. Estimates the overall expense of operating applications in the AWS Cloud compared with on premises.
    Answer: AWS Total Cost of Ownership (TCO) Calculator

42. Uses unused EC2 capacity and can provide up to a 90% discount compared with On-Demand pricing.
    Answer: Spot Instance

43. Consolidates multiple AWS accounts into a centrally managed organization with organizational units.
    Answer: AWS Organizations

44. Provides cost-effective long-term archival storage with expedited, standard, and bulk retrieval options.
    Answer: Amazon Glacier

45. A platform where vendors can sell a catalog of custom AMIs and other solutions.
    Answer: AWS Marketplace

46. An S3 feature that uploads one object as independently uploaded contiguous parts.
    Answer: Multipart Upload

47. Combines payment for multiple AWS accounts into one payment method and summarizes their usage and costs.
    Answer: Consolidated Billing

48. Provides detailed AWS resource-usage and estimated-charge data for an account.
    Answer: AWS Cost and Usage Reports

49. Distributes incoming traffic across healthy targets and scales load-balancing capacity as traffic changes.
    Answer: Elastic Load Balancer (ELB)

50. Geographic areas containing AWS infrastructure that let customers place applications closer to users or meet compliance requirements.
    Answer: AWS Regions

51. One or more discrete data centers with redundant power, networking, and connectivity in separate facilities.
    Answer: Availability Zones

52. Region-scoped machine images whose copies can be created in other AWS Regions.
    Answer: Amazon Machine Images (AMIs)

53. An interactive query service that uses SQL to analyze data directly in Amazon S3 and other data sources.
    Answer: Amazon Athena

54. A Well-Architected pillar focused on developing, running, monitoring, and continuously improving workloads and supporting processes.
    Answer: Operational Excellence

55. An object-storage service that stores objects in buckets.
    Answer: Amazon Simple Storage Service (Amazon S3)

56. Displays metrics, creates alarms, sends notifications, and can trigger changes when monitored thresholds are breached.
    Answer: Amazon CloudWatch

57. Extends CloudWatch Events capabilities and connects data from AWS services, applications, and third-party SaaS applications.
    Answer: Amazon EventBridge

58. Helps investigate security findings and identify their root cause.
    Answer: Amazon Detective

59. A managed DDoS protection service for applications running on AWS.
    Answer: AWS Shield

60. Lets you create rules that filter web traffic by IP address, HTTP header, request body, or custom URI.
    Answer: AWS WAF

61. A failover configuration with primary resources normally active and secondary resources on standby.
    Answer: Active-Passive Failover

62. A data-warehouse service that can operate without a provisioned cluster and scale capacity for unpredictable workloads.
    Answer: Amazon Redshift

63. A fully managed relational database engine compatible with MySQL and PostgreSQL.
    Answer: Amazon Aurora

64. A serverless compute technology for running Amazon ECS containers without managing EC2 servers or clusters.
    Answer: AWS Fargate

65. A fully managed message-queuing service that sends, stores, and receives messages between software components.
    Answer: Amazon Simple Queue Service (Amazon SQS)

66. Connects to the same distributed storage volume as an Aurora primary DB instance and supports read operations.
    Answer: Aurora Replica

67. The AWS Cloud Adoption Framework perspective that aligns technology and business by evolving culture, organizational structure, leadership, and workforce.
    Answer: People perspective

68. A cloud-computing advantage that lets applications be deployed in multiple Regions worldwide quickly.
    Answer: Go global in minutes

69. Serverless, elastic shared file storage that removes the need to manage storage capacity and performance.
    Answer: Amazon Elastic File System (Amazon EFS)

70. Provides block-level storage volumes for use with EC2 instances.
    Answer: Amazon Elastic Block Store (Amazon EBS)

71. Provides rugged, secure devices for using AWS compute and storage at the edge and transferring data to and from AWS.
    Answer: AWS Snowball

72. Links on-premises environments to AWS cloud storage for secure hybrid-storage integration.
    Answer: AWS Storage Gateway

73. A cloud best practice based on service-oriented architecture that prevents component failures from cascading.
    Answer: Decouple your components

74. Evaluates newly created IAM policies before or while they are used.
    Answer: IAM Policy Simulator

75. The party responsible for patching the host operating system beneath an Amazon EC2 instance.
    Answer: AWS

76. Securely transfers hundreds of petabytes or exabyte-scale datasets into and out of AWS.
    Answer: AWS Snowmobile

77. The S3 operation used to upload a single object in parts for better throughput and faster recovery from network issues.
    Answer: Use Multipart Upload API

78. The lowest support plan in this question set that permits an unlimited number of technical support cases.
    Answer: Developer Support Plan

79. A single place to view the availability and operations of AWS resources and the overall status of AWS services.
    Answer: AWS Health Dashboard

80. A managed publish-and-subscribe service used to send notifications from the cloud.
    Answer: Amazon Simple Notification Service (Amazon SNS)

81. Executes a series of jobs on one or more computers without manual intervention.
    Answer: Batch computing

82. Simplifies deploying and managing applications in the AWS Cloud.
    Answer: AWS Elastic Beanstalk

83. Simplifies virtual-desktop delivery by reducing the need to manage hardware inventory, operating system versions, patches, and VDI.
    Answer: Amazon WorkSpaces

84. An open-source container-orchestration system for deploying and managing containerized applications at scale.
    Answer: Kubernetes

85. A table class that can reduce DynamoDB storage cost for infrequently accessed data.
    Answer: DynamoDB Standard-IA

86. An Auto Scaling capability that analyzes past traffic and predicts future traffic to schedule capacity adjustments.
    Answer: Predictive Scaling

87. A cryptographic service for creating and maintaining hardware security modules in an AWS environment.
    Answer: AWS CloudHSM

88. An AWS authorization strategy that defines permissions using attributes.
    Answer: Attribute-based access control (ABAC)

89. Continuously assesses, audits, and evaluates resource configurations and relationships across AWS and supported hybrid environments.
    Answer: AWS Config

90. Permissions that grant users only the minimum access needed to perform required tasks.
    Answer: Least-privilege permissions

91. A container-management service that runs, stops, and manages Docker containers on a cluster.
    Answer: Amazon Elastic Container Service (Amazon ECS)

92. A managed service that simplifies creating, operating, and scaling relational databases in the cloud.
    Answer: Amazon Relational Database Service (Amazon RDS)

93. Automatically increases RDS storage capacity as database workloads grow without downtime.
    Answer: RDS Storage Auto Scaling

94. A cloud-powered business-intelligence service for visualizations, ad-hoc analysis, and data insights.
    Answer: Amazon QuickSight

95. Estimates the cost of AWS services from specified usage parameters.
    Answer: AWS Pricing Calculator

96. Executes large volumes of batch-computing jobs on AWS efficiently.
    Answer: AWS Batch

97. A simplified service for individuals and small businesses to launch and manage virtual private servers.
    Answer: Amazon Lightsail

98. A managed service that simplifies deploying, managing, and scaling Kubernetes clusters.
    Answer: Amazon Elastic Kubernetes Service (Amazon EKS)

99. Compiles source code, runs tests, and produces deployable software packages.
    Answer: AWS CodeBuild

100. A cloud-based contact-center service designed to provide customer service at lower cost than traditional contact centers.
    Answer: Amazon Connect
